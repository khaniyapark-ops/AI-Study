# 수강생 환경 준비 가이드 (Windows · macOS)

> 교육 **1주 전**에 배포하고, 수강생은 마지막 단계의 **환경 점검**까지 마친 결과를 강사에게 회신합니다.
> 망분리·폐쇄망 PC여도 괜찮습니다. 기본 데모는 오프라인 재생, 심화 실습은 모의 실행으로 인터넷 없이 진행할 수 있습니다.

## 1. 무엇이 필요한가

| 과정 | 필요한 것 | 인터넷 |
|---|---|---|
| 기본 과정 데모 | 웹 브라우저 (Edge · Chrome) | 불필요 (라이브 모드만 필요) |
| 기본 과정 실습 | Python 3.10 이상, pytest | 설치할 때만 |
| 심화 과정 모의 실행 | Python 3.10 이상, pytest | 설치할 때만 |
| 라이브 실행 (선택) | 위 + Anthropic SDK + API 키 | 필요 (`api.anthropic.com` 접속) |

## 2. 설치

### 2-1. Python
| Windows | macOS |
|---|---|
| python.org에서 Python 3.11 이상 설치. 설치 첫 화면에서 **"Add python.exe to PATH" 체크** | 터미널에서 `python3 --version` 확인. 없거나 3.10 미만이면 python.org에서 설치 |
| 사내 PC라 설치가 막히면 사내 소프트웨어 센터에서 신청 | |

설치 확인:
| Windows (PowerShell) | macOS (터미널) |
|---|---|
| `py -3 --version` | `python3 --version` |

### 2-2. 교육 자료 복사
강사가 준 교육 자료 폴더 전체를 **쓰기 가능한 위치**에 복사합니다. 예: `C:\edu\workspace-aidevedu`, `~/edu/workspace-aidevedu`
- OneDrive 동기화 폴더, 네트워크 드라이브, 경로가 아주 긴 위치는 피하세요.

### 2-3. 실습용 패키지
| Windows (PowerShell) | macOS (터미널) |
|---|---|
| `cd C:\edu\workspace-aidevedu` | `cd ~/edu/workspace-aidevedu` |
| `py -3 -m pip install pytest` | `python3 -m pip install pytest` |

라이브 실행까지 하려면 (선택):
| Windows | macOS |
|---|---|
| `cd advanced\agent_lab` | `cd advanced/agent_lab` |
| `py -3 -m venv .venv` | `python3 -m venv .venv` |
| `.venv\Scripts\python -m pip install -r requirements.txt` | `.venv/bin/python -m pip install -r requirements.txt` |

> Windows에서 `.venv\Scripts\Activate.ps1` 실행이 "스크립트 실행 정책" 때문에 막혀도 괜찮습니다. 위처럼 `.venv\Scripts\python`을 직접 부르면 활성화 없이 쓸 수 있습니다.

## 3. 환경 점검 (필수)

| Windows | macOS |
|---|---|
| `py -3 setup\check_env.py` | `python3 setup/check_env.py` |

마지막 "판정" 네 줄을 캡처해 강사에게 회신하세요. ❌ 항목에는 조치 방법이 함께 나옵니다.

```
기본 과정 (브라우저 데모 오프라인 재생): 가능
기본 과정 실습 (pytest 버그 수정)    : 가능
심화 과정 모의 실행                  : 가능
라이브 실행 (실제 Claude 호출)        : 준비 필요 (선택 사항)
```

## 4. 교육 중 쓰는 명령 대응표

| 하는 일 | Windows | macOS |
|---|---|---|
| 기본 데모 열기 | `demo\index.html` 더블클릭 | `demo/index.html` 더블클릭 |
| 실습 테스트 실행 | `cd sample-system` → `py -3 -m pytest -q` | `cd sample-system` → `python3 -m pytest -q` |
| 심화 모의 실행 | `cd advanced\agent_lab` → `py -3 agent.py --pack settle --mock` | `cd advanced/agent_lab` → `python3 agent.py --pack settle --mock` |
| 평가 | `py -3 eval.py` | `python3 eval.py` |
| 마스킹 | `py -3 mask.py samples\ticket_with_pii.txt` | `python3 mask.py samples/ticket_with_pii.txt` |
| API 키 설정 (라이브) | `$env:ANTHROPIC_API_KEY="sk-ant-..."` | `export ANTHROPIC_API_KEY=sk-ant-...` |
| 라이브 실행 | `.venv\Scripts\python agent.py --pack settle` | `.venv/bin/python agent.py --pack settle` |

> 교재와 슬라이드의 `python3 ...` 명령은 Windows에서 `py -3 ...`로 바꿔 입력하면 됩니다.
> API 키는 터미널 창 안에서만 유지되고 창을 닫으면 사라집니다. 파일에 적어 두지 마세요.

## 5. 자주 막히는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| `python`을 입력하면 Microsoft Store가 열림 | Windows의 앱 실행 별칭 | `py -3`를 사용하거나, 설정 → 앱 → 앱 실행 별칭에서 python 끄기 |
| `pip install`이 시간 초과·SSL 오류 | 회사 프록시·방화벽 | 사내 프록시 주소를 `HTTPS_PROXY`에 설정하거나, 아래 '오프라인 설치' 사용 |
| 한글이 깨지거나 이모지에서 오류 | 콘솔 인코딩(cp949) | Windows Terminal 사용 권장. 그래도 깨지면 `$env:PYTHONUTF8="1"` 설정 후 다시 실행 |
| `.venv` 생성이 막힘 | 백신·보안 정책 | 라이브 실행만 영향받음. 모의 실행은 venv 없이 가능 |
| `api.anthropic.com 연결 불가` | 망분리·폐쇄망 | 정상입니다. 기본 데모는 오프라인 재생, 심화는 모의 실행으로 진행 |
| 데모 페이지 라이브 모드 오류 | 인터넷 차단 또는 키 오류 | 키 칸을 비우면 오프라인 재생으로 돌아감 |

### 오프라인 설치 (인터넷 PC에서 미리 받아 가기)
인터넷이 되는 PC에서 수강생 PC와 **같은 OS·같은 Python 버전**으로 받습니다.
```bash
python3 -m pip download -r advanced/agent_lab/requirements.txt -d wheels
```
받은 `wheels` 폴더를 교육 자료와 함께 옮긴 뒤 수강생 PC에서 설치합니다.
```bash
python3 -m pip install --no-index --find-links wheels pytest
```
(Windows는 `python3` 대신 `py -3`)

## 6. 강사용: 당일 대체 진행

| 상황 | 대체 진행 |
|---|---|
| 수강생 PC에 Python 설치 불가 | 기본 데모(브라우저)만 개인 실습, pytest·심화 실습은 **강사 화면 시연 + 짝 관찰 기록지** |
| 강의장 인터넷 차단 | 데모 오프라인 재생 + 심화 모의 실행. 라이브 결과는 심화 슬라이드 26~27의 실측 결과로 설명 |
| 일부만 환경 불가 | 가능한 수강생과 짝을 지어 진행 (관찰 기록지 활용) |
| API 키 사용 불가 (보안 정책) | 라이브 실습 생략. `security/AI도입_보안판단가이드.md`로 "왜 못 쓰는가"를 토론 주제로 전환 |

> 이 가이드의 Windows 명령은 이 교육 자료를 만든 macOS 환경에서 cp949 출력 환경을 흉내 내어 점검했습니다. **실제 Windows PC에서는 강사가 교육 전에 한 번 점검 스크립트를 돌려 확인하세요.**
