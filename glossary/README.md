# Agentic AI 핵심 용어집

용어 35개(전 직무 필수 ★ 7개)를 6장으로 정리한 교육자료입니다. **원본은 `terms.json` 하나**이고, 아래 자료는 모두 여기서 생성됩니다.

| 파일 | 용도 |
|---|---|
| `terms.json` | 용어 원본: 정의 · 비유 · 교육 장면 · 흔한 오해 · 예문 · 관련 용어 · 직무 |
| `용어카드집.pptx` | 카드 46장 (표지·읽는 법·용어 지도·직무별 지도 + 장 표지 6 + 용어 35 + 자가 점검) |
| `용어요약표_A4.pdf` / `.pptx` | A4 가로 한 장 요약 (책상 비치·회의용) |
| `웹용어집.html` | 검색 · 장/직무 필터 · ★필수만 · 카드 상세 · 퀴즈 · 인쇄용 표. 브라우저로 바로 열면 됨(오프라인) |
| `사업용어_표준안.md` | 표기 원칙, 대역표, 쓰지 말 표현, 문서 유형별 예문, 개정 절차 |

## 교육 과정에서 쓰는 법

- **기본 과정 사전 학습 (20분)**: 웹 용어집에서 "★ 필수만"을 켜고 7개 카드 읽기 → 퀴즈 한 번
- **심화 과정 1일차 오프닝 (30분)**: 용어 지도 슬라이드 → 짝끼리 카드 한 장씩 설명 → 웹 퀴즈
- **수료 후**: 웹 용어집과 A4 요약표를 사업 공용 자료로 배포. 보고서·제안서는 `사업용어_표준안.md`를 따름

## 용어를 고친 뒤 다시 만들기

1. `terms.json` 수정
2. 웹 용어집 (Python만 필요):
   ```bash
   python3 build_web.py
   ```
3. 카드집과 A4 요약표 (Node.js + pptxgenjs 필요):
   ```bash
   npm install pptxgenjs
   ```
   ```bash
   node .build_cards.js
   ```
   - 테마 색을 입히는 도구(`APPLY_THEME` 환경변수로 경로 지정)가 없으면 Office 기본 색으로 저장됩니다. 내용은 같고 색만 다릅니다.
   - A4 PDF는 PowerPoint나 LibreOffice에서 `용어요약표_A4.pptx`를 PDF로 내보내 만듭니다.
4. `사업용어_표준안.md` 대역표에 새 용어 반영
